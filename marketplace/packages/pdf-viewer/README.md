# PDF Viewer

View PDF files directly inside Sam Code.

## Features

- **Built-in PDF rendering** using PDF.js — no external viewer needed
- **Multi-page navigation** — jump between pages with prev/next controls
- **Zoom controls** — zoom in, zoom out, or fit to width/page
- **Dark-mode themed UI** — matches the Sam Code editor aesthetic
- **Keyboard shortcuts** — arrow keys for page navigation, `+`/`-` for zoom

## How it works

When you open a `.pdf` file in Sam Code, the PDF Viewer extension replaces the standard code editor with a dedicated PDF reader. The PDF is loaded as binary data and rendered using the PDF.js library from a CDN.

## Installation

Install from the Sam Code Marketplace by clicking **Install** on the PDF Viewer card.

## Requirements

- Internet connection (loads PDF.js from CDN on first use)
- No additional system dependencies required
